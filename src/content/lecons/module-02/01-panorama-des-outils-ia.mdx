En 2026, une IA peut écrire en quelques secondes un script qui t’aurait pris une heure. Il en existe beaucoup, et elles ne font pas toutes la même chose. Certaines complètent la ligne que tu tapes, d’autres travaillent seules dans ton projet pendant de longues minutes. Cette leçon fait le tour des outils utiles pour créer l’Obby des Nuages, de ce qu’ils coûtent au moment de la rédaction (octobre 2026) et de ce qu’ils ne feront jamais à ta place.

## Deux familles d’IA de code

On peut ranger les outils en deux grandes familles.

| | Assistant dans l’éditeur | Agent de code |
|---|---|---|
| Ce qu’il fait | Propose la suite d’une ligne, répond à une question, écrit un script dans le fichier ouvert | Lit le projet, modifie plusieurs fichiers, lance des commandes (Git, selene…), lit le résultat et corrige |
| Qui pilote | Toi, ligne par ligne | Toi, tâche par tâche : tu décris le but, il enchaîne les étapes |
| Exemple | Code Assist dans l’éditeur de scripts de Studio | Claude Code |
| Risque principal | Accepter une suggestion sans la lire | Le laisser modifier beaucoup de choses sans relire |

Un **agent** est donc un programme qui agit, et pas seulement un programme qui suggère. C’est beaucoup plus puissant, et c’est aussi plus de responsabilité pour toi. Beaucoup d’outils proposent désormais les deux modes, et la frontière bouge vite.

<Info titre="Un mot que tu vas souvent croiser : MCP">
Le **MCP** (*Model Context Protocol*) est une norme ouverte qui permet de brancher une IA sur un autre logiciel. Roblox Studio intègre un **serveur MCP** : une IA externe, comme Claude Code, peut alors lire ton place, modifier des scripts ou lancer un test. Tu l’installeras dans la leçon 2.
</Info>

## Claude Code, l’agent choisi par la formation

D’après sa documentation, Claude Code est un outil de code « agentique » d’Anthropic qui lit ton code, modifie des fichiers, lance des commandes et s’intègre à tes outils de développement. Il fonctionne à plusieurs endroits :

- dans un **terminal**, la version la plus complète, que la formation utilise ;
- dans **VS Code**, avec une extension (elle marche aussi dans Cursor), ou dans les éditeurs **JetBrains** ;
- dans l’**application de bureau** Claude (onglet **Code**) pour macOS et Windows ;
- sur le **web** (claude.ai/code) et dans l’application mobile. Ces sessions tournent dans le cloud, sur une copie de ton dépôt : elles ne peuvent pas atteindre le Studio ouvert sur ton ordinateur.

### Offres et prix (octobre 2026)

Claude Code demande un compte payant : la documentation cite les comptes Pro, Max, Team, Enterprise et Console (facturation à l’usage de l’API). L’offre gratuite ne l’inclut pas. Prix relevés sur la page officielle, en dollars américains, hors taxes éventuelles :

| Offre | Prix affiché | Remarque |
|---|---|---|
| Free | 0 $ | Pas de Claude Code |
| Pro | 20 $ par mois, ou 17 $ par mois en payant l’année d’avance (200 $) | Le point de départ pour un projet personnel |
| Max | « À partir de 100 $ » par mois | Deux niveaux : 5 fois et 20 fois l’usage de Pro |
| Team | 20 $ (Standard) ou 100 $ (Premium) par siège et par mois en annuel ; 25 $ ou 125 $ en mensuel | Pour une équipe |

Claude Code partage les limites d’usage du reste de ton abonnement. Ces prix changent : **vérifie toujours la page officielle** avant de t’abonner.

<Attention titre="Claude Code : 18 ans et plus">

Claude Code est réservé aux personnes de **18 ans et plus** (conditions d’utilisation d’Anthropic, octobre 2026). Si tu as moins de 18 ans, ne crée pas de compte et n’utilise pas seul celui d’un parent. Tu peux :

- travailler avec un adulte (parent, enseignant) qui utilise Claude Code avec son propre compte ;
- utiliser l’Assistant intégré à Roblox Studio, soumis aux règles de Roblox ;
- ou suivre la formation en lisant et en tapant toi-même : les prompts et la méthode de relecture restent utiles.

Pour les autres outils de cette page, lis leurs conditions d’utilisation avant de créer un compte.

</Attention>

## L’Assistant intégré à Roblox Studio

L’**Assistant** est l’IA de Roblox, directement dans Studio : on l’ouvre avec le bouton **Assistant**, à droite de la barre d’outils. D’après la documentation (octobre 2026), il peut :

- répondre à tes questions sur le développement Roblox et expliquer le code sélectionné ;
- **créer et modifier des objets et des scripts** dans le place ouvert, plusieurs à la fois (par exemple un RemoteEvent, un LocalScript et un Script) ;
- insérer des assets du Creator Store, générer des matériaux, des maillages 3D et des modèles procéduraux ;
- préparer un plan avant d’agir : choisis **Plan** dans la liste déroulante du champ de saisie, ou tape `/plan`. Le plan est un document modifiable, et rien ne s’exécute tant que tu n’as pas cliqué sur **Build** ;
- suivre des **skills** : des fiches d’instructions en Markdown (par exemple tes conventions de nommage) que tu gères dans **…** › **Assistant Settings** › **Skills**. Roblox en fournit aussi, comme `rbx-debug` ou `rbx-unit-test` ;
- utiliser un modèle d’Anthropic, d’OpenAI ou de Google avec ta propre clé d’API (**…** › **Manage API Keys**, puis le menu **Model**). Une clé d’API se paie à l’usage chez son fournisseur.

À côté de l’Assistant, **Code Assist** propose des complétions pendant que tu tapes dans l’éditeur de scripts (`Tab` pour accepter).

**Ce qui n’est pas publié** : au moment de la rédaction, Roblox n’indique ni prix ni quota général pour l’Assistant. Le seul chiffre officiel est une limite de 50 modèles procéduraux par fenêtre glissante de 24 heures. Tout autre chiffre que tu lirais ailleurs est à prendre avec méfiance.

**Ses limites pour un projet comme l’Obby** : le code vit dans le place, pas dans des fichiers versionnés avec Git. Les discussions sont rattachées au place. Et la documentation prévient elle-même que le script généré « peut ne pas fonctionner parfaitement ».

## Les autres IA de code

D’autres outils sérieux existent. Tous évoluent très vite : voici leur situation sur leur page officielle en octobre 2026 (prix mensuels en dollars américains).

| Outil | Ce que c’est | Offres affichées | Bon à savoir |
|---|---|---|---|
| **Cursor** | Éditeur de code centré sur l’IA, avec agent | Free 0 $, Plus 8 $, Premium 30 $, Super 100 $, Ultra 200 $ | L’offre Plus est limitée aux modèles Grok ; les modèles tiers sont facturés au prix de leur API à partir de Premium |
| **GitHub Copilot** | Assistant et agent dans VS Code et d’autres éditeurs, plus un outil en ligne de commande | Free 0 $, Pro 10 $, Pro+ 39 $, Max 100 $ | Usage compté en « AI Credits » (1 crédit = 0,01 $) ; l’offre gratuite est limitée |
| **OpenAI Codex** | Agent en ligne de commande et application, inclus dans ChatGPT | ChatGPT Free 0 $, Go 8 $, Plus 20 $, Pro à partir de 100 $ | L’offre gratuite sert surtout à découvrir l’outil sur de petites tâches |
| **Google Antigravity** | Plateforme de développement par agents (éditeur et outil en ligne de commande) | « Sans frais » pour les développeurs individuels | Pour les comptes gratuits et Google One, Antigravity CLI a remplacé Gemini CLI le 18 juin 2026 |

Leur point commun : ce sont des outils généralistes, qui ne connaissent pas Roblox mieux que Claude Code. Ce qui fait la différence, c’est **ton projet** (fichiers, conventions, vérifications) et **la précision de tes prompts**. Bonne nouvelle : le serveur MCP de Studio propose un branchement rapide pour plusieurs d’entre eux (Antigravity, Codex CLI, Claude Code, Claude Desktop, Cursor, Gemini CLI et Visual Studio Code). Ce que tu apprends dans ce module reste donc utile si tu changes d’outil.

En 2026, des offres ont été renommées, des outils remplacés (Gemini CLI), des éditeurs ont changé de modèles du jour au lendemain. Un tutoriel ou une vidéo de l’an dernier est souvent faux. Avant de payer ou de suivre une procédure, ouvre la **page officielle** de l’outil et regarde sa date.
</Erreur>

## Quand utiliser quoi

| Ta tâche | Outil conseillé | Pourquoi |
|---|---|---|
| Petite retouche dans le place ouvert (couleur, position, une propriété) | Assistant de Studio | Il voit le place et agit directement |
| Comprendre un script ou une erreur de l’Output | Assistant de Studio, ou Claude Code | Les deux expliquent bien ; Claude Code voit aussi les autres fichiers du projet |
| Générer un modèle 3D, une texture, un matériau | Outils IA de Roblox (leçon 9) | Ce sont des outils spécialisés, intégrés à Studio |
| Nouveau système de jeu (checkpoints, boutique, sauvegarde) | Claude Code + Rojo + Git | Plusieurs fichiers, un plan validé, un commit par étape |
| Refactorisation, renommage dans tout le projet | Claude Code en mode plan | Il trouve toutes les occurrences, et tu valides le plan avant |
| Relecture de sécurité ou de performances | Claude Code (sous-agent relecteur, leçon 6) | Il lit tout le code d’un coup, avec ta checklist |
| Tester le jeu en vrai, lire la console de Studio | Claude Code + serveur MCP de Studio | Il lance le test et lit l’Output lui-même |

<Astuce titre="Combiner plutôt que choisir">
Les outils ne s’excluent pas. Un bon réflexe : le gros du code avec Claude Code dans le projet Rojo, une retouche rapide d’objets avec l’Assistant, et dans tous les cas **un commit Git avant chaque gros changement**, pour pouvoir revenir en arrière.
</Astuce>

## Ce que tu envoies à l’outil

Une IA de code envoie ton travail à des serveurs pour le traiter. Avant de l’utiliser, sache ce qui part :

- **Claude Code** tourne sur ton ordinateur, mais envoie à Anthropic tes prompts et les réponses du modèle, donc aussi le contenu des fichiers qu’il lit pour travailler. Pour les comptes grand public (Free, Pro, Max), c’est toi qui choisis si tes données peuvent servir à améliorer les modèles, dans les réglages de confidentialité de claude.ai. La documentation indique une conservation de 5 ans si tu l’acceptes et de 30 jours sinon.
- **Le serveur MCP de Studio** transmet à l’IA ce que ses outils lisent : scripts, propriétés, console, captures d’écran.
- **L’Assistant de Studio** stocke les discussions dans le cloud de Roblox. Les conditions d’utilisation de Roblox interdisent d’y soumettre des données personnelles ou confidentielles, et te rendent responsable de tes prompts et de l’usage des résultats.

<Attention titre="Jamais de secret dans un prompt">
Ne colle **jamais** dans un prompt, un fichier du projet ou une capture : ton mot de passe, ton cookie `.ROBLOSECURITY` (il donne un accès complet à ton compte), une clé d’API, ton adresse ou ton numéro de téléphone. Si un outil ou une personne te le demande « pour tester », c’est une arnaque.
</Attention>

## Pourquoi la formation choisit Claude Code

C’est une **décision de la formation**, pas un classement objectif. D’autres outils conviennent aussi. Nous avons choisi Claude Code comme outil principal pour cinq raisons :

1. Il travaille sur un projet **entièrement décrit en fichiers** (Rojo), versionné avec Git, comme le corrigé de la formation.
2. Un fichier **CLAUDE.md** lui rappelle à chaque session l’architecture et les règles de sécurité de l’Obby (leçon 3).
3. Le **mode plan**, les **permissions** et les **hooks** te gardent aux commandes : il propose, tu valides, et `selene` et StyLua vérifient automatiquement.
4. Il sait **relire** avec un sous-agent et **tester** dans Studio grâce au serveur MCP, qui prend en charge Claude Code en branchement rapide.
5. Sa documentation officielle est détaillée et à jour, ce qui nous permet de vérifier chaque commande enseignée.

## Ce que l’IA ne remplace pas

Aucune de ces IA ne connaît ton jeu mieux que toi. Elles peuvent inventer une fonction qui n’existe pas, oublier une vérification côté serveur ou proposer une méthode dépréciée, avec un ton parfaitement assuré. Trois choses restent ton travail :

- **comprendre** assez le code pour le relire (c’est l’objet des modules 3 à 5) ;
- **tester** : un code qui « a l’air bon » n’a de valeur qu’une fois essayé dans Studio, à plusieurs joueurs si besoin ;
- **décider** : ce que fait le jeu, ce qui est juste pour les joueurs, ce qui est publié.

Et la règle d’or de tout ce module : **plus ton prompt est précis (contexte, objectif, contraintes, critères de réussite), meilleur est le résultat. Un prompt vague donne du code vague.** On n’apprend plus à tout taper, on apprend à **lire, diriger et vérifier**.

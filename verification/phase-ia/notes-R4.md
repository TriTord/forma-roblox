### Leçon 08 — Les pièges de l'IA
- Tags Deprecated vérifiés dans les YAML de la référence (script Python sur `RobloxGlobals.yaml`, `Player.yaml`, `Humanoid.yaml`, `BodyVelocity.yaml`, `BodyPosition.yaml`, `MarketplaceService.yaml`, `BasePart.yaml`, `Model.yaml`, `Instance.yaml`) : `wait`, `spawn`, `delay`, `Player:LoadCharacter`, `Humanoid:LoadAnimation`, `BodyVelocity`, `BodyPosition`, `BasePart.Velocity`, `MarketplaceService:GetProductInfo`, `Model:SetPrimaryPartCFrame`, `Instance:Remove` = Deprecated ; `workspace`, `game`, `Animator:LoadAnimation`, `LoadCharacterAsync`, `GetProductInfoAsync`, `PromptProductPurchase` = pas de tag. `BodyGyro`, `BodyForce`, `BodyAngularVelocity`, `game.workspace`, service `Chat`, `TeleportService:Teleport` (sans tag), `Instance.new(class, parent)` (déconseillé) : repris de la veille I sans re-téléchargement.
- `loadstring` désactivé par défaut, `ServerScriptService.LoadStringEnabled` = false, « recommended to keep this disabled… remote code execution » — `ServerScriptService.yaml`, `LuaGlobals.yaml`.

Ordre de lecture de la pile (« première ligne = endroit du plantage, puis les appelants ») : conforme au test (une seule ligne de pile dans mes deux tests) et au comportement habituel de Luau, mais je n'ai pas observé de pile à plusieurs niveaux dans ce test (la fonction intermédiaire a été inlinée par le compilateur : la ligne affichée était `Line 3 - function surContact`).
